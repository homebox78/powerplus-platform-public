# powerMCP 실호출 테스트 보고서 (2026-10-10)

로컬 powerMCP(도구 47개)에 네 모듈별로 질문 20개 이상을 실제로 던지고, 응답을 읽어 결함을 찾은 뒤 고쳐 다시 돌린 결과다.

- 환경: 로컬 MCP `localhost:3199` → 로컬 API `127.0.0.1:8090/api/v1`(로컬 DB = 운영 덤프). `mock_` 도구는 운영 mockref API 를 거친다.
- 키: staff(임직원) · free(외부 무료) 두 계정의 시험 키. 시험 끝나고 폐기.
- 총 99문항: powerAssets 24 · powerDeck 23 · powerMock 30 · powerGuide 22.
- "1차"는 수정 전, "고친 뒤"는 수정 후 같은 질문을 다시 돌린 결과다.
