## 3차 (2026-10-08 오후) — 잘림 검사 추가

점검 도구에 **상자 안 잘림**(overflow hidden·clip 상자가 자손을 오른쪽에서 자름, 말줄임·떠 있는 요소 제외)과 `ONLY=` 화면 골라 보기를 더했다.
2차까지는 문서 폭만 봐서, 넘침 0 인데 버튼 줄이 상자 안에서 잘리는 화면을 놓쳤다. 첫 판은 직계 자식만 봐서 또 놓쳤다 — 자손 전체를 본다.
Git Bash 에서 `ONLY=/deck/...` 은 MSYS 가 Windows 경로로 바꾼다 → `MSYS_NO_PATHCONV=1`.

| 화면 | 문제 | 고침 |
|---|---|---|
| 장표 작업 머리 줄(`.pd .head`) | 56px 한 줄 고정이라 768·390 에서 버튼·입력칸이 잘림 | 1024 미만 줄바꿈 허용(높이 자동), 640 미만 좌우 여백 16·세그먼트 버튼 축소 |
| 장표 단계 표시(StepTrail) | 단계 이름 9개가 한 줄을 넘침 | 768 미만은 지금 단계만 이름, 나머지는 번호(이름은 화면 낭독용으로 남김) |
| 장표 작업 정보 줄 | 메타 칩이 한 줄 고정 | 줄바꿈 허용 |
