### 6. 요구사항 구조
- 분류: SFR·ECR·PER·SIR·DAR·TER·SER·QUR·COR·PMR·PSR (총 38건)
- 건수: SFR 6 / ECR(시스템) 1 / PER 2 / SIR 3 / DAR 4 / TER 3 / SER 2 / QUR 1 / COR 7 / PMR 5 / PSR 4
- 가장 비중 큰 분류: 건수는 COR(7), 실질 분량·난도는 SFR(공통 54종+개별 37종 전면 재개발).
- 특이·고난도 요구사항:
  - **SFR-004/005**: 업무지원 공통업무 54종·개별업무 37종을 **MSA 구조로 전면 재개발**, 1차 표준화가이드·공통모듈·4개 테마 디자인 적용, 관리자 교육 후 서비스 오픈
  - **SFR-002**: Polling → **SSE(Server-Sent Events) 실시간 알림** 구현, 긴급알림 연계
  - **SFR-003**: 개인정보 이력관리(조회·삭제·수정·다운로드) + **2단계 표출(마스킹→본인인증→표출)**
  - **DAR-03**: **Oracle → PostgreSQL** 마이그레이션, 개인정보 포함파일 삭제 후 이관, 정합성 결과서
  - **SIR-003**: 연계 20종을 **API 방식으로 일원화하여 1차 중계서버에 탑재**
  - **COR-004**: 전자정부 표준FW + 1차 사업 FW(**spring cloud, module federation**) 준수
  - PER-002: 응답 3초, 동시 1,000명, 메인페이지 3MB 이하 / TER-002: 통합테스트에 구축 미참여 **공인자격 보유 제3자 포함**
  - SFR-006/DAR-04: 폐기예정·유지 서비스 처리방안(단순조회·DB보관)

**목차 구조**
- RFP: 개요(배경·범위·기대효과) → 현황 → 추진방안(목표·전략·체계·일정) → 제안요청내용(총괄표·목록·상세) → 제안안내(자격·낙찰·제출·평가) → 작성지침 → 붙임(배점·서식·보안). 전시사업만 "과업 지침" 중심.
- 제안서 지정 목차는 거의 동일(일반현황 → 전략·방법론 → 기술·기능 → 성능·품질 → 프로젝트관리 → 프로젝트지원 → 상생/하도급 → 기타)이며 **배점표와 1:1 대응**. 요구사항 수용 조견표·평가항목 조견표(참조표)를 별도 요구.

### D. 발표 평가에서 점수를 가르는 핵심 포인트 TOP 10
1. **PM이 직접, 규정 인원·시간 안에서 발표** — 위반 시 발표 점수 자체가 사라진다(인천·한전기술 "서류만 평가", 전시 "불참 실격"). [인천, 한전기술, MPAS, 스마트교육, 전시]
2. **발표자료 = 제출 제안서(요약서)** — 상이 내용은 별도 명기, 추가 불가; 장표는 제안서 목차·배점표 순서대로 구성해야 참조표와 맞는다. [스마트교육, 인천, 한전기술, 전시, MPAS]
3. **최대 배점 항목 한 장에 집중** — 기능 요구사항(굿모닝 10), 사업추진내용(인천 10), 수조 설치계획·연출기법(전시 각 10), 공사 요구사항(한전기술 20). 평가기준 문구("구체적이고 적절하며 실현 가능한지")를 그대로 장표 제목·체크리스트로 쓴다. [전 문서]
4. **목표시스템 구성도·개념도**는 "사업이해도" 평가요소에 명시(굿모닝 "목표시스템 구성의 적정성", MPAS, 스마트교육, 한전기술 "목표구성도·핵심전략"). [굿모닝, MPAS, 스마트교육, 한전기술]
5. **연속사업·현황 문제점을 숫자로 재진술** — 1차 산출물(굿모닝), '08 구축·'24 이관(MPAS), 두레이·오프라인(스마트교육), 문제점 표 10건(한전기술), 2·3층 중복 회피(전시). 발주처가 쓴 문제점을 그대로 되돌려 주는 장표가 이해도 점수를 만든다. [전 문서]
6. **사람(인력) 장표** — 참여인력·PM 역량이 직접 배점(인천 10+5, 한전기술 "PM 기술성 3·조직 3", MPAS "구현 경험 담당자 투입", 전시 기술인력 4). 이름·직무·경력연수·자격·투입률을 표로. [인천, 한전기술, MPAS, 전시]
7. **데이터 이관·연계·보안의 '검증 절차'** — 배점 기준이 "검증 방법·에러 처리·책임 조직"을 묻는다(굿모닝 DAR 3·SIR 3, MPAS 데이터 5·보안 5, 스마트교육 데이터 5). 절차도+검증표+책임자. [굿모닝, MPAS, 스마트교육]
8. **상생협력·하도급 선언** — 하도급 없음/10% 이하 표준계약 → 만점(스마트교육 5, MPAS 5). 하도급 불허 사업(굿모닝·인천·전시)에서는 자사 인력 100% 조직도가 신뢰 근거. [스마트교육, MPAS, 굿모닝, 인천, 전시]
9. **지원부문(교육·기술이전·시범운영·하자·비상)을 구체 일정과 수치로** — 한전기술 지원 20점(홍보동영상·패턴분석 이전·시범운영), 인천 기술인계 10, MPAS 2h/4h, 굿모닝 품질보증 5(인증 우대). [한전기술, 인천, MPAS, 굿모닝]
10. **감점·실격 체크리스트 선행** — 업체 식별 표시(인천 △1, 전시 실격), 규격·매수 초과(전시 △5), 동영상·홍보 내용(스마트교육·인천·한전기술), 사회적책임·신인도(굿모닝·인천·한전기술·전시), 퇴직자 확인서(한전기술), 모호한 표현("할 수 있다" → 불가능 간주, 스마트교육·인천·한전기술·전시). 발표 전 자동 검수 항목으로 삼아야 한다. [전 문서]
