## 등록할 때 (이게 빠지면 시안에 안 나온다)
- 카테고리 **mockup_sample**(또는 공개 사진) + 태그 축 **kind** 1개 — 목업 샘플 풀은 `kind` 태그가 있는 자산만 받는다(`MockSamples::sampleWhere`). 일반 사진으로만 올리면 시안에서는 워터마크가 찍히거나 404 다.
  - kind 값: `hero-city`·`hero-nature`(첫 화면) / `sub-visual`(서브 띠) / `place`(시설) / `citizen`(사람·활동) / `news-thumb`(소식 썸네일) / `poster`(세로 포스터) / `card-news` / `icon-set`
- 태그 축 **target** = 기관 종류: `univ`·`school`·`library`·`welfare`·`culture`·`biz`·`assoc`·`corp`·`gov`·`local` — 이게 있어야 그 종류 시안에 먼저 뽑힌다(새로 만든 `library` 포함).
- 사진 안에 **글자·로고·실존 기관명 금지**(프롬프트에 no text 포함). 비율은 표의 값으로(서브 띠 2400×1018, 소식 3:2).
