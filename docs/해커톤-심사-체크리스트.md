## 1. AI 심사가 바꾸는 것 — 먼저 읽기

AI 심사는 **발표자료와 영상에 보이는 것만** 근거로, **다른 팀과 비교해** 점수를 매긴다. 심사기준 외 설명은 받지 않는다.

- [ ] 주장마다 **화면에 보이는 증거**(수치·캡처·시연 장면)가 붙어 있다. "편리합니다", "혁신적입니다"는 점수가 되지 않는다.
- [ ] 장표 제목이나 소제목에 **심사 기준 낱말을 그대로** 쓴다(실용성·창의성·완성도·확장성). 기준과 증거가 어디서 만나는지 읽는 쪽이 찾지 않게 한다.
- [ ] **전/후 비교 수치**가 최소 3개 있다(시간·비용·품질 중). 상대평가라 숫자가 없으면 숫자가 있는 팀보다 낮게 나온다.
- [ ] 영상 속 글자는 캡처만 봐도 읽힌다(작은 글 18px 이상, 대비 충분 — R42 와 같은 기준).
- [ ] 영상과 자료가 **같은 이야기 순서**다(자료 쪽 번호 = 영상 장면 순서).
- [ ] 과장 표현이 없다. 확인할 수 없는 큰 수치는 근거 없는 주장으로 읽혀 오히려 깎인다.

## 6. 제출 전 최종 점검

### 6.1 자료·영상 공통
- [ ] 기준 4개가 **비율 순서(실용성→창의성·완성도→확장성)** 로 다뤄지고, 각 기준에 장표 1장 이상
- [ ] 수치는 모두 날짜와 출처(운영 DB·측정)를 붙였다
- [ ] 영상 길이가 대회 제한 안이고, 첫 30초에 "무엇을 해결하나"가 나온다
- [ ] 자막 또는 화면 글로 핵심 수치가 다시 보인다(음성만으로 말하지 않는다)

### 6.2 노출 금지 (하나라도 걸리면 제출 보류)
- [ ] **발주처 실물 자료**(실제 제안서 장표·발주처 실명)가 화면·자료에 없다
- [ ] **엠바고 사업명**이 글자로 박힌 장표·파일이 없다
- [ ] 개인 계정·개인 도메인·개인 메일이 화면에 없다(주소창·설정 화면 주의)
- [ ] API 키·토큰이 화면에 없다(MCP 설정 장면 가림)
- [ ] 시연 시안 속 실제 지명이 발주처와 겹치지 않는다(예: 가상 기관명 시안 본문에 실제 지명이 남은 것 — 확인 필요)
- [ ] 공개 저장소는 `scripts/export-public.sh` 누출 검사 통과본만

### 6.3 수치 갱신 쿼리(제출 직전)

```sql
SELECT 'users',COUNT(*) FROM core_users UNION ALL
SELECT 'assets',COUNT(*) FROM asset_items UNION ALL
SELECT 'asset_uses',COUNT(*) FROM asset_uses UNION ALL

SELECT 'deck_done',COUNT(*) FROM deck_jobs WHERE status='done' UNION ALL
SELECT 'mock_passed',COUNT(*) FROM mock_mockups WHERE deleted_at IS NULL AND passed=1 UNION ALL
SELECT 'gallery',COUNT(*) FROM mock_gallery WHERE status='shared' UNION ALL
SELECT 'checklist_fixed',COUNT(*) FROM mock_checklist WHERE status='fixed';
```
