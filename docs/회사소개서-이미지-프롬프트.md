# 회사소개서 테마 · 목업 회사 홈페이지 — 이미지 생성 프롬프트

> 용도 두 가지: ① `engine/company.py` 회사소개서 테마(표지·간지·마무리 배경, 큰 그림, 카드 아이콘)
> ② powerMock 목업 회사 홈페이지(히어로·섹션 배너·소개·채용·연락처).
> 생성기: Higgsfield `nano_banana_2_1`(배경·실사), 투명 오브젝트는 생성 뒤 `remove_background`.

## 0. 먼저 지킬 규칙 (만들기 전에 읽기)

| # | 규칙 | 이유 |
|---|---|---|
| 1 | **색은 코발트 블루 한 색 + 무채색만.** 다른 색을 섞지 않는다. | 엔진 `tint_icon` 은 #1F4FFF 기준으로 **색조만 돌려** 11개 톤(크림슨·에메랄드·바이올렛…)으로 바꾼다. 빨강·주황이 섞이면 돌린 뒤 엉뚱한 색이 된다. 흰·회·검은 부분은 그대로 남는다. |
| 2 | **글자·숫자·로고·간판·UI 화면 글씨 금지.** | 어느 회사에도 써야 하고, 글은 엔진이 얹는다. |
| 3 | **정면 인물 금지.** 사람은 뒷모습·손·실루엣·멀리 흐릿하게만. | 2026-10-14 지시. 초상권·범용성. |
| 4 | **피사체는 오른쪽(또는 오른쪽 아래), 왼쪽 55% 는 비운다.** | 표지·간지 글이 왼쪽에 앉는다. 엔진 `bg_is_light` 는 왼쪽 절반 평균 밝기로 글자색을 정한다 — 왼쪽은 고르게 밝거나 고르게 어두워야 한다. |
| 5 | **업종 무관 공통 구조.** 공장·병원·음식처럼 업종이 드러나는 그림 X. | 회사소개서 엔진은 업종을 모른다. |
| 6 | **흐린 페이드 마감 금지.** 경계는 또렷한 면·선·곡선으로. | 2026-10-15 "흐지부지 그라데이션 끝 X". |
| 7 | **1~2장 먼저 → 톤 3개(blue·crimson·emerald)로 돌려 확인 → 나머지.** | 크레딧. 한 번에 다 돌리지 않는다. |

**크기**: 장표 배경 16:9(1920×1080 이상) · 홈페이지 히어로 21:9(2560×1080) · 섹션 배너 3:1 · OG 1200×630 · 오브젝트·아이콘 1:1.

**등록 이름**(배경 세트 `cp-bg-theme`): 엔진이 이름에서 테마 낱말·역할 낱말을 찾는다.
`<역할> <테마> 회사소개서 배경 <간지 낱말>` — 예: `간지 다크 회사소개서 배경 기술 역량`.
역할 = 표지·간지·마무리 / 테마 = 다크·라이트·솔리드·프렌들리 / 간지 낱말 = 회사·소개 | 기술·역량 | 성장·성과.

### 공통 꼬리 (모든 프롬프트 뒤에 붙인다)

```
no text, no letters, no numbers, no logos, no watermark, no UI text, no human faces, color palette strictly limited to cobalt blue (#1F4FFF) and neutral white/gray/black, no other hues, crisp clean edges, high resolution, commercial stock quality
```

## 7. 만들고 나서 확인

1. 톤 3개로 돌려 본다: `python -c "import company as c; c.tint_icon('x.png','x_crimson.png','crimson')"` (engine 폴더) — 파랑이 아닌 색이 튀면 다시.
2. 왼쪽 절반 밝기 확인: `c.bg_is_light('x.png')` — 라이트 테마는 True, 다크·솔리드는 False 가 나와야 한다.
3. 회사소개서 샘플로 한 번 뽑아 본다: `scripts/company-sample.py` → 표지·간지에 글이 그림과 겹치지 않는지, 여백 검사 `scripts/company-padcheck.py` 통과.
4. 등록 이름은 위 "등록 이름" 규칙대로(세트 `cp-bg-theme`). 아이콘은 `icon-flat-blue-glass`.
