# powerDeck 공용 디자인 가이드

> 제안설명회 본문 장(머리 띠 아래 본문 영역)을 기획·시안·장표로 만들 때 따르는 공통 규칙.
> 머리 띠·사업명(오른쪽 위)·바닥 선·발주기관/제안사 로고·쪽번호는 **슬라이드 마스터**에 엔진이 넣는다 — 본문 시안에 그리지 않는다.
> 디자인 타입(A~F)마다 다른 것은 `styles/styles.json`(본문 포인트·그림 화풍)이 이 가이드보다 먼저다. 표지·목차·간지는 `학습-표지목차간지.md`.
> 실제 장표 542장에서 배운 헤드라인·레이아웃 문법은 `학습-컨텐츠모음.md`. 사용자가 짚은 장표 수정 사항은 `worker/build_checklist.md`.
> 마지막 정리: 2026-10-04 (OO시 가이드 v1 → 컨텐츠모음 2차 전수 학습·사용자 수정 요청 반영)

## 1. 색 — 파랑 4단계 + 강조색 하나

실제 장표는 거의 모두 **같은 파랑을 중요도에 따라 4단계로** 쓴다. 모든 도형과 글을 한 톤 파랑으로 칠한 장은 가치가 낮다(D022·D030·D036·D112).

| 단계 | 색 | HEX | 쓰는 곳 |
|---|---|---|---|
| ① 핵심 | 딥 네이비·딥 코발트 | #0B2E6B ~ #1E40AF | 결론 띠, 주 패널 머리, 핵심 숫자, 장의 가운데 요소 하나, 헤드라인 글 |
| ② 보조 | 코발트 | #3B82F6 | 카드 제목, 라벨, 아이콘, 화살표·연결선, 탭, 막대 |
| ③ 바탕 | 스카이·옅은 파랑 | #DBEAFE ~ #EFF6FF | 카드·패널 바탕, 배경 도형, 화면 틀 |
| ④ 설명 | 회색 | #6B7280(글) · #E5E7EB(선) · #1F2937(본문 글) | 설명, 캡션, 테두리, 비활성·현재(AS-IS) |
| 강조 | 작업의 강조색(기본 #FF2A6D) | 중간 채도 | 헤드라인 속 핵심어 1~3개, 핵심 KPI 하나, 경고·차별점 배지("추가제안") |

- 한 장에 네 단계가 모두 보여 눈이 ①→②로 간다. 큰 그림(모니터·기기)은 ②~③, ①로 다 칠하지 않는다.
- **강조색은 글자와 작은 배지에만.** 도형 면을 강조색으로 칠하지 않는다. 한 장에서 강조가 세 군데를 넘지 않는다.
- **단계·연차·발전은 연한 → 진한 순서**(같은 파랑). 오른쪽·바깥으로 갈수록 진하면 "심화"로 읽힌다(D440·D468·D478·D500·D522).
- 글과 바탕은 밝기 대비가 커야 한다(어두운 바탕에는 흰 글). 형광·네온 색, 그림자 과다 금지.
- 디자인 타입 F 는 강조색 한 가지로 면과 글을 다 쓴다(styles.json 의 accent_main).

## 2. 서체

새 변환에서 **제목 서체 하나 + 본문 서체 한 벌(굵기 4단계)** 을 고른다(`worker/fonts/fonts.json`, 첫 줄이 기본).

- 제목 서체(기본 G마켓 산스 Bold · 페이퍼로지 · 하나서체 · MBC 1961): **키메시지(헤드라인)**, 표지 사업명, 목차의 '목차'·장 이름, 간지의 PART 번호·장 이름 — 20pt 이상 큰 글자.
- 본문 서체(기본 a시월구일 · 프리텐다드 · 원티드 산스 · 에이투지체)의 4단계 — 굵기는 bold 속성이 아니라 서체 이름으로 가른다.

| 단계 | 쓰는 곳 |
|---|---|
| 1 옅음 | 옅은 설명, 주석 |
| 2 본문 | 본문, 카드 안 목록 |
| 3 강조 | 소제목, 강조어, 표지 슬로건·'제안설명회'·날짜 |
| 4 굵음 | 카드·패널 제목, 띠 글, 표 머리, 숫자 |

글자 크기(사용자 최종판 실측 — 이 사용자의 밀도):

| 구분 | pt | 단계 |
|---|---|---|
| 키메시지 | 25 (한 줄, 가운데) | 제목 서체 |
| 패널 머리 | 18 | 3 · 흰 |
| 카드 제목 | 12 | 3~4 |
| 본문 | 8 | 2 |
| 카드 안 목록 | 7 ~ 7.5 | 2 |
| 주석·작은 라벨 | 6 ~ 6.5 | 1~2 |
| 아래 결론 띠 | 11 | 3 · 흰 |
| 강조 숫자 | 21 이상 | 4 · 그 장에서 가장 큼 |

- 같은 종류(group)의 칸은 같은 크기·굵기·정렬. 칸마다 글을 줄이지 않는다 — 넘치면 줄을 바꾸거나 폭을 넓힌다.
- 줄간격은 **고정 pt**(글자 크기 × 1.5 안팎). 도형 안 한 줄 글만 100%.
- 한 줄로 놓는 글(쉐브론·배지·알약·띠)은 서체 파일로 폭을 재서 도형 안쪽 폭 95% 안에 들어가게.
- 표지·목차·간지의 큰 글자: 자간 = 크기 × −1.7%(35.5pt 에 '좁게 0.6pt'), 줄간격 = 크기 × 1.18pt 고정(35.5pt 에 42pt).
- 강제 줄바꿈 대신 칸 폭으로 자연스럽게. 단어 중간("포 털")에서 끊기지 않게. 말줄임표 '…' 금지.

## 3. 레이아웃

- **한 장 = 큰 덩어리 3개**(좌·중·우 또는 위·가운데·아래). 비율은 고르게 나누지 않는다(25:50:25, 30:40:30, 40:60 — 주인공이 가장 넓다). 33:33:33 은 비교표일 때만.
- 가장 흔한 뼈대: **왼쪽 문제 → 가운데 도식 → 오른쪽 목록 → 아래 전폭 딥 네이비 결론 띠**(D047·D057·D061·D063).
- 열은 5개 이하. 카드는 3~5개, 같은 종류는 같은 크기, 번호 배지(01~05)나 체크.
- 좌우 여백 40~56px, 카드 간격 12~20px, 모서리 12~16px, 아래에 작은 빈 여백.
- **안쪽 여백은 균일**: 카드 안 좌우·위아래 같은 여백(카드 폭의 약 3%). 같은 종류 카드는 머리 높이·글 시작 위치가 같다.
- 아이콘이 있는 카드: 아이콘 왼쪽, 제목·설명은 옆에 왼쪽 정렬로 한 열.
- 제목과 설명은 붙이지 않는다(제목 아래 간격). 같은 줄의 윗선·같은 열의 왼선을 한 값으로 맞춘다.
- 화살표는 흐름이 있을 때만, 큰 화살표 1~2개가 작은 화살표 여럿보다 낫다.
- 연속 장은 같은 틀 + (1/3)(2/3)…, 1/2 는 표·도식, 2/2 는 실제 화면.

### AS-IS → TO-BE (현재 대 제안)
- **비율**: AS-IS 30~40% · TO-BE 55~65% — 제안 쪽이 늘 더 넓다.
- **색**: AS-IS 는 회색 머리·흰/회색 패널에 작게, TO-BE 는 딥 네이비 머리 패널에 크게(D144·D146·D179). 사이는 큰 코발트 화살표, '+', 사다리꼴 확대 띠(D408·D441·D482·D528).
- **증거**: 양쪽에 실제 화면 캡처, TO-BE 시안 화면에는 빨강 원 '예시' 배지(D010).
- **차이 짚기**: 강조색 콜아웃("10년 기술 차이" D154), 결과 상자에 숫자("75%→최소화" D066). 아래 3칸 고도화 요약.
- 다른 꼴: 위 AS-IS·아래 TO-BE 타임라인(D066·D067), 왼쪽 불편 흐름(인물+말풍선) → 오른쪽 시스템화 화면(D015), 빨간 X ↔ 파랑 체크 같은 행 짝(D095), 이슈·해결·효과 3열(D068).

### 숫자와 증거
- 핵심 숫자는 따로 떼어 가장 크게: 배지, 강조색 테두리 상자(100%↓), 말풍선(60.5%→100%), 아래 큰 숫자 3개, 합계("총 8명"), 월계관("28년").
- 증거는 실물: 실제 화면 캡처·휴대폰/모니터 목업, 기사, 표창장, 공문·인증서, 고객기관 로고 그리드, 인력 사진·경력 카드.
- 작아서 글자가 안 읽히는 캡처·스윔레인·문서는 넣지 않는다(크게 넣거나 뺀다).

## 4. 그림

- **그림이 주인공이 아니다.** 장표는 어떤 메시지를 전할지 — 맥락과 내용이 먼저다. 인물·사진·일러스트는 메시지를 돕는 보조로 본문의 35% 이하, 글(현황·문제·수치·근거·결론)은 글 상자에. 실사 타입도 사진 콜라주로 장을 덮지 않는다.

- 화풍은 디자인 타입이 정한다: A 3D 클레이 · B 데이터 실사 합성(실사 + 빛나는 시안 데이터 그래픽) · C 헥사곤 실사 · D 인물 실사 · E 아이소메트릭 3D 미니어처(흰 광택 받침 + 빛나는 파랑) · F 선화 플랫. 이 덱의 표지 그림이 본문 화풍 견본. 타입끼리 화풍이 확연히 달라야 한다.
- 실사·합성·편집·3D 렌더(B·C·D·E) → 표지·목차·간지·본문 모두 나노바나나 2(GPT 는 실사에서 얼룩이 심하다 — Higgsfield·OpenRouter 공통). 일러스트·아이콘(A·F) → gpt-image-2.5 flare.
- 인물은 한국인, 성인 비율(치비 금지), 한 장에 1~3명, 역할(고민·설명·조작·악수)이 있을 때만. 클레이·인물은 장의 10~15% 포인트.
- 그림 안에 글자·브랜드·로고 노출 금지. 표지·목차·간지 그림은 정면 얼굴 금지(뒷모습·옆모습·손).
- 아이콘: 코발트 기본, 딥 코발트 강조. 같은 장에서 아이콘 중복 금지. 빈 곳은 그림으로 채우고 글 칸은 키우지 않는다.
- 표지·목차·간지끼리 같은 그림을 되풀이하지 않는다. 간지는 조용하게.

## 5. 글 — 헤드라인·말투

- 헤드라인은 한 줄 20~34자, 세 꼴: **약속문**("…하겠습니다/합니다"), **명사구+수식**("A부터 B까지 빈틈없이 관리"), **질문·전환**("그런데 현실은?"). 큰따옴표로 감싸고 가운데 정렬하는 경우가 많다.
- 핵심어 1~3개만 강조색. 강조어는 결과를 말하는 낱말("빈틈없이", "정예", "25년")에, 사업명·기관명에는 주지 않는다.
- 수치를 앞에, 대구("과거도 정비하고 미래도 준비")로 두 줄을 끊는다.
- 본문은 공공 SI 제안서 말투 — 짧은 명사형 끝맺음("…관리", "…지원"). 같은 사실을 한 줄로 줄이는 것은 되지만 **항목·수치·이름·단계를 빼지 않는다.** 자료에 없는 수치·이름은 만들지 않는다.
- 발표 대본: 한 장 1분 안팎, 한 줄에 한 문장, 화면 글을 그대로 읽지 않고 근거를 말로 푼다.

## 6. 초안을 받아 만들 때 (품질 기준)

사용자: **"내가 제안서 초안을 주고 만들어 라고 하면 지금 퀄리티가 나와야 함."** 기준은 사용자가 손으로 고쳐 넘긴 최종판이다(OO시 v0.78 — 41장 중 30장, 1,494곳을 고쳤다).

순서
1. **글 덩어리는 부품으로 다시 짠다**(아래 표). 글 상자를 다듬는 데서 멈추지 않는다.

3. 기본 글자는 §2 실측값. "글자 키워 줘"는 **그 칸에만** 적용한다.
4. 정렬은 눈대중이 아니라 실측(같은 줄 윗선·같은 열 왼선·카드 간격).
5. 결과 장을 시안과 나란히 놓고 같은 밀도·같은 부품인지 본다. 글이 크거나 휑하거나 글 덩어리가 남아 있으면 다시 짠다.

## 7. 금지 / 권장

금지
- 모든 도형·글을 같은 파랑 한 톤으로
- 도형 면을 강조색으로 칠하기, 한 장에 강조 세 곳 이상
- 디즈니풍·치비 인물, 과한 카툰, 그림 속 글자·로고
- 흰 바탕 + 흰 글, 그림자 과다, 형광색
- 같은 크기 카드를 번호만 바꿔 늘어놓기, 주인공 없는 같은 비율
- 헤드라인이 절 제목("2. 품질관리") 그대로인 장
- 말줄임표 '…', 단어 중간 줄바꿈
