# SI 장표 마감 — 초안 .pptx → 납품본 (+ powerPlus 연계)

포트폴리오·회사소개서(웹 덱)는 `hom2box-deck`, **업무 제안·SI 장표는 이 스킬**이다. 증적도 따로 쌓는다.
새로 짓는 게 아니라 **여러 사람이 만든 초안을 한 사람이 만든 것처럼** 톤·서체·그림·도식·줄바꿈을 정리한다.

## 품질 기준 — 사용자 최종판이 기준이다
"초안 주고 만들어"를 받으면 `references/quality-bar.md` 를 먼저 읽고 `gold-sample/` 기준 그림 41장을 연다. 결과는 매 장 기준 그림과 같은 밀도·같은 부품이어야 한다.

- 본문은 8pt, 카드 목록은 7~7.5pt, 주석은 6.5pt.
- 글 덩어리는 카드·번호 목록·단계 칩·결론 띠로 **다시 짠다.**
- 같은 줄 도형의 정렬은 실측해서 맞춘다.
- 사용자가 손으로 고쳐 넘기면 `hand_diff.py` 로 무엇을 고쳤는지 재서 이 기준을 갱신한다.

## 먼저 — OO시 회고에서 나온 다섯 가지 (자세히 `references/retro-sample.md`)

1. **내용이 먼저다.** 원본의 항목·수치·이름·단계·연결선·강조는 빼지 않는다. 같은 사실을 한 줄 키워드로 짧게 하는 것은 된다(사용자도 그렇게 고쳤다). 시안은 겉모습의 기준이지 글의 기준이 아니다. 매 판 끝에 `text_diff.py` 로 원본에만 있는 글이 없는지 본다.
2. **글이 자리를 잡고 그림은 남는 자리에.** 아이콘·일러스트가 글을 작게 만들면 안 된다(기본은 아이콘 카드 높이 40% 안팎, 본문 8~9pt).
3. **색·서체·띠 규격은 처음에 견본으로 한 번 고르게 하고 잠근다.** 디자인시스템 문서 맨 위 "잠긴 값"에 적고, 바꾸면 스크립트 한 줄로 전 장에 다시 적용한다. 값은 스크립트에 박지 않는다.
4. **한 장에서 짚인 것은 바로 전 장 규칙으로.** dry-run 목록을 찍고, 손으로 맞춘 장은 제외 목록에 넣는다.
5. **조립 순서 한 파일로 언제든 다시 만들 수 있게** (`restore/vNNN_chain.sh`). 글 위치를 바꾸는 도구(세로 가운데·줄바꿈)는 맨 끝에 한 번. 단, 사용자가 손으로 고친 판이 오면 그 위에 요청한 것만 적용한다.

## 0. 지키는 원칙

0. **장표만 받으면 묻지 않고 `autopilot.md` 전체를 돈다.** 시작할 때 파일에 '이미지 압축 안 함'을 기록한다(그림 깨짐의 원인).
1. **원본·이전 판은 덮어쓰지 않는다.** 받자마자 `<이름>.원본백업.pptx`, 이후 판은 `_v0.N_<한일>.pptx`. 사용자가 열어 둔 파일(`~$` 잠금 파일 존재)은 새 이름으로 저장.
2. **노랑 기획 메모(스마일·FFFF00·FFFFCC…)·말풍선 '애매' 등은 내용을 건드리지 않는다.** 납품 전 슬라이드쇼에서 숨기려면 지우지 말고 슬라이드 오른쪽 밖으로(`memo_offslide.py`). 모든 도구가 제외. 분홍 '디자인' 지시 말풍선은 9단계에서만 제거.
3. **증빙은 교체하지 않는다** — 실제 시스템 화면 캡처·인증서·회사 로고·인물 사진·지도.
4. **판정은 속성이 아니라 렌더로.** PowerPoint 가 무시하는 속성(`eaLnBrk`)이 있고, COM 저장이 python-pptx 결과를 되돌리기도 한다.
5. **자동 감사 결과는 보정 후보다.** 렌더로 확인하고 깨지면 원위치. 목표는 "위반 0"이 아니라 **남은 건이 전부 설명 가능한 예외**.
6. **일괄 스크립트 뒤엔 반드시 전 장 렌더 재검수.** 규칙 하나가 다른 구조의 카드에서 조용히 사고를 낸다.
7. **크기는 내림만, 0.25pt 단위 최대 2pt.** 하한은 6.5pt(주석·작은 라벨), 본문 8pt. "키워 달라"는 요청은 그 칸에만 적용한다.
8. **문구를 바꾸면 반드시 목록으로 보고**하고 확인을 받는다(띄어쓰기 보정 포함).
9. 결과는 PowerPoint 로 **직접 열어서** 보여 준다(`Start-Process`). 글로 경로만 알려 주지 않는다.

## 3. powerPlus 연계 한눈에 (자세히는 `references/powerplus.md`)

- **자산 찾기**: 공개 API `https://hom2box.com/powerPlus/api/public/assets?q=&category=icon` → `find.py` 시트로 **눈으로** 고른다(태그 매칭은 빗나간다).
- **스타일 세트**: 한 장표 안은 한 세트로 — 아이콘 3D 295종(`icon_1263` 계열) · 인물 3D 94종(`illust_187` 계열). 세트 목록은 서버 `AssetService::styleSet`(키가드 임시 러너)으로 받는다.
- **교체**: 이미지는 `set_swap.py`(지정표 json, 잉크 영역 맞춤·다시칠하기·hdphoto 제거), 도형 아이콘은 `shapeswap_*`.
- **역방향**: 완성 장표를 powerPlus 에 **전체본 1 + 낱장 N** 으로 등록(`optimize → split → render → dump → sheet → meta → stage → import-ppt.php`), 서버에서 `curl localhost` 로 한글 검색 검증, 등록 후 로컬 원본 삭제.
