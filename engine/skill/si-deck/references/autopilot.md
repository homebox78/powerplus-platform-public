# 자동 마감 — 장표 하나만 받았을 때

목표(사용자, 2026-09-30): **"장표만 하나 넣어 주면 말하지 않아도 지금까지 한 과정이 전부 가공돼 나온다."**
지시가 없어도 아래를 위에서 아래로 전부 돈다. 묻는 것은 맨 끝 "확인 목록"에 모아 한 번에 보고한다.
사용자가 OO시 장표에서 **직접 짚어 준 것**을 먼저 찾는 목록이다 — 짚이기 전에 찾는 것이 이 문서의 목적.

## 0. 시작 (질문 없이)
0. **받자마자 '이미지 압축 안 함'을 파일에 기록**(`presentation.xml` `p14:defaultImageDpi val=32767`). 안 하면 PowerPoint 저장 때마다 그림이 표시 크기×220ppi 로 줄어 키우면 깨진다. 레지스트리 `AutomaticPictureCompressionDefault=0` 도 확인.
1. 원본 백업 → `_v0.1_…` 부터 판을 올린다. 열려 있으면 `SaveCopyAs`.
2. 실측 4종(`tone_audit` `pic_survey` `tone_overflow` `line_scan`) + 전 장 렌더 시트.
3. **디자인 시스템 문서부터 만든다**(`design-system.md` 순서: 실측 → 역할별 한 값 → `<프로젝트>_디자인시스템.md`). 서체·팔레트를 묻지 않고 기본값을 쓰되 장표에 이미 지배적인 값이 있으면 그것을 따른다. 끝에서 이 문서 기준으로 한 번 더 검수한다.
4. 표준 1~9단계(`process.md`)를 돈다.

## 2. 끝
- 재검수 3회(`review.md`) → 점수표.
- PowerPoint 로 연다.
- 보고: 판 이름 / 탐지 목록별 건수 / 문구 바꾼 곳 / **확인 목록**(판단이 갈린 것: 자산 교체 후보, 예외로 둔 것, 투명도 같은 취향 값).
- `evidence.md`·가이드·커밋.

## 3. 아직 자동이 아닌 것 (정직하게)
- 탐지 2·8·13·20 은 **눈 판정**이 들어간다 — 시트를 만들어 직접 본다. 규칙만으로 돌리면 오판한다.
- 고침 도구 일부가 OO시 전용 스크립트(`*.sample.py`)다. 새 장표에서 같은 유형을 만나면 **그 스크립트를 일반 도구로 승격**하고 이 표의 '고침' 칸을 갱신한다. 두 번째 장표에서 승격하지 않으면 또 손으로 하게 된다.
- 사용자가 새로 짚는 것이 나오면 **그 자리에서 이 표에 행을 추가**한다. 이 표가 곧 "말하지 않아도 되는 것"의 범위다.
