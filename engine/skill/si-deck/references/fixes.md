# 증상별 수정법 — 증상 → 원인 → 고치는 법 → 확인법

실제로 겪고 고친 것만 적는다. 새로 겪으면 여기에 한 항목 추가.

## 서체

| 증상 | 원인 | 고치는 법 | 확인 |
|---|---|---|---|
| 서체를 통일했는데 일부 글자가 굴림·산돌·맑은 고딕·Pretendard 로 나온다 | 런에 서체가 없어 글상자 `lstStyle defRPr`·테마 기본값을 물려받음 | `font_inherit.py` 로 기본값까지 교체 | `tone_audit` 서체 분포에 "서체 없는 런이 어디서 물려받는지" 포함 |
| Bold 서체를 강조로 보냈더니 라벨이 접히고 문서가 무겁다 | 굵기로 역할을 가름 | 기본 본문, **흰 글자이거나 12pt↑만** 강조 | 렌더 크롭 |
| 흰 글자 판정이 44런을 놓침 | 흰색이 `schemeClr bg1` 로 지정 | `srgbClr FFFFFF`·`bg1`·`prstClr white`·`fontRef lt1` 모두 | 강조 런 수 전후 비교 |
| 작은 표 머리에 G마켓(제목 서체) | 템플릿 잔재 | 14pt 미만 G마켓 → 강조 서체(`smallfont_rule.py` 류) | `tone_audit` |
| 합성 굵게(b=1)가 서체 볼드와 섞임 | 사람이 Ctrl+B | `unbold_font.py` — b 해제 + 강조 서체. latin·ea **둘 다** 확인(ea 만 보면 G마켓 제목 런까지 바뀜) | `tone_audit` 합성 굵게 0 |

## 색

| 증상 | 원인 | 고치는 법 | 확인 |
|---|---|---|---|
| 색이 160종 | 장마다 다른 사람 | `tone_color.py` 근접색 스냅(가중 RGB + hue 벌점 + 채도 가드), 임계 넘는 색은 남기고 보고 | `tone_audit` 팔레트 밖 색 |
| 그라데이션 밴드가 평면이 됨 | 스톱까지 스냅 | 스톱 제외. 판정은 `getparent()` 조상 체인(**`id()` 식별 금지**) | 그라데이션 수 전후 동일 |
| 도식마다 색 계열이 다르다(회색·칙칙한 회청·밝은 파랑이 섞임) | 도식을 여러 사람이 여러 도구로 | `color_unify.py` — 회색/회청 채우기를 밝기표로 파란 팔레트로. 흰 글자 칸은 658EBB 이상. 그다음 **도식 간 역할 색 통일**(아래) | 도식 장끼리 나란히 컨택트시트 |
| 도식끼리 역할 색이 제각각(시작 상자·판단 마름모·결과 상자·보조 설명이 장마다 다른 색) | 한 도식씩 따로 재제작 | 역할→색 표를 가이드에 정하고 도식 장 전체에 적용(`diagram_roles.py`) | 도식 장만 모은 시트 |
| 키메시지 색이 장마다 다름(강조 EB696D, 나머지 검정·tx1·002060 혼재) | 장마다 다른 사람 | 사용자가 지목한 **기준 장**의 런 색을 COM 으로 읽어(열린 문서에서 — 저장 전 수정일 수 있다) 전 장 키메시지에 적용: 빨간 계열 런 → 기준 강조색, 나머지 → 기준 글자색(테마색이면 ObjectThemeColor 로). `keymsg_color.py` | 상단 띠 크롭 스트립 + 픽셀 최빈색이 기준 장과 같은지 |
| 연한 칸이 중간 파랑으로 칠해짐 | 흰 글자 판정에 밝은 칸 포함 | 밝기 ≥0.8 칸은 흰 글자 판정에서 제외 | 렌더 크롭 |
| 어두운 도형 위 연노랑 글자 | 옛 강조 관행 | 흰색으로(OO시 59곳) | 렌더 |
| 분홍으로 바뀐 줄 알았다 | 크롭 좌표 착시 | 원본과 **같은 좌표** 픽셀 비교 | 픽셀값 |

## 크기·넘침·줄바꿈

| 증상 | 원인 | 고치는 법 | 확인 |
|---|---|---|---|
| 소수 pt(8.5·9.75) | 복붙 | `tone_size.py` 내림(확대 없음) | 크기 종류 |
| 멀쩡한 정수까지 줄어듦(15→14) | 표준 스케일 배열에 빠진 값 | "정수는 그대로, 소수만 내림" | 크기 분포 |
| 서체 교체 후 넘침 | 폭 변화 | `tone_overflow` 로 원본과 위치 키 대조, **새로 넘친 것만** `tone_fit` | 새 넘침 0 |
| 단어가 줄 중간에서 끊김 | 좁은 칸 | `fit_breaks.py`: 0.25pt 축소(최대 2, 7 하한) → 어절 앞 `chr(11)` → 보고 | `line_scan` |
| `eaLnBrk="0"` 넣었는데 그대로 | PowerPoint 가 무시 | 위 방법(렌더 줄 기반) | 렌더 비교 |
| 합성어가 한 줄보다 길다 | "연계표준가이드라인" | 띄어쓰기로 풂 — **문구 변경 보고** | |
| 마지막 줄에 1~2글자 | 고아 줄 | `orphan_balance.py`(윗줄 마지막 어절 앞 줄바꿈, 크기 불변). 크기를 줄이면 형제 도형 톤이 갈린다 | `line_scan` |
| 형제 카드끼리 글자 크기가 다름 | 카드별 축소 | 형제 전체를 한 값으로(OO시 s16 8장 7.25pt) | `tone_audit` 형제 크기 차 |
| "—" 든 문단이 2줄로 접힘 | 긴 제목 | `dash_linebreak.py` 대시 뒤 줄바꿈(여러 문단 제목은 제외) | |
| 자간이 너무 좁아 글자가 겹쳐 보임 | 크기 -10% 초과 음수 자간 | `spc_relax.py` → 바로 `fit_breaks.py` | `line_scan` 새 끊김 0 |

## 그림

| 증상 | 원인 | 고치는 법 | 확인 |
|---|---|---|---|
| 새 아이콘이 원본보다 작아 보임 | 3D 아이콘 자체 여백 | 원본 잉크 영역(알파 bbox)에 트림한 새 그림을 맞춤(`set_swap`·`swap`) | 3단 비교 시트 |
| 교체한 그림이 저장 후 옛 그림으로 | 예술 효과 원본 레이어(`a14:imgProps → hdphoto`) | 레이어 제거(`set_swap`·`mass_even` 내장) | **COM 저장 후** 렌더 |
| 교체 그림이 다른 색으로 칠해짐 | 다시 칠하기(duotone·clrChange)·srcRect | set_swap 이 제거 | 렌더 |
| 한 장만 바꿨는데 여러 장이 바뀜 | 미디어 파트 공유 | 도형마다 새 파트(set_swap), 또는 split 후 교체 | 다른 장 렌더 |
| 아이콘이 사라짐(s14) | 박스 뒤 가려진 큰 그림을 교체하고 보이는 걸 지움 | **렌더에 보이는 것** 기준으로 대상 선택(z-order) | 렌더 |
| 진한 원 안 3D 아이콘이 묻힘 | 흰 선 아이콘 자리 | 원을 흰 바탕 + 같은 색 테두리, 아이콘 지름 62% | 렌더 |
| 크기가 제각각 | 자리마다 다른 bbox | `mass_even.py` 같은 줄/열·같은 종류 √면적 중앙값 | 렌더 |
| 원 안 아이콘과 타일 아이콘이 서로 끌려감 | 한 무리로 묶임 | 크기 비슷한 것만 묶기 | |
| 인물 크기가 맞아도 어긋나 보임 | 흉상 vs 전신 | 같은 구도 그림으로 교체 | |
| 같은 장에 같은 아이콘 반복 | 종류→자산 1:1 | 종류당 대체 3개, `icon_dedupe.py` | 해시 중복 0 |
| 얇은 선 자리 아이콘이 너무 작음 | 작은 bbox | `icon_enlarge.py` 최소 0.30in | |
| 도형 아이콘 일부가 안 잡힘 | 탐지 한 방식 | circle + cluster(선 포함, 군집 0.17in) 반복, 남는 게 화살표·번호뿐일 때까지 | 크롭 시트 |

## 도식·선·레이아웃

| 증상 | 원인 | 고치는 법 | 확인 |
|---|---|---|---|
| 선 굵기가 제각각 | 여러 손 | `diagram_lines.py` 0.5pt·25%(장식·그라데이션·옅은 구분선 제외) | 로그 수량 |
| 선이 글자를 관통 / 화살표가 상자에 안 닿음 | 재제작 좌표 | 명세 수정 후 `rebuild_on.py` | 확대 렌더 |
| 마름모 안 글자 넘침 | 마름모 글상자가 좁음 | 위에 글상자를 따로 얹음 | |
| 흰 글자에 흰 얼룩 | 글상자 3D + 좁은 자간 | `text3d_off.py` | 확대 렌더 |
| 정렬 후 설명이 헤더 띠 위로 | 이동량 상한 없음 | 상한 0.12~0.25in | 렌더 |
| 아이콘이 글자 위로 떨어짐 | 스택 구조에 좌우 규칙 | 구조를 먼저 가르고 스택 제외 | 렌더 |
| 가이드 밖으로 전부 잡힘 | 머리말 그림자·장식 측정 | 2.3cm 위 마스크 + 가장자리에 닿고 글 없는 도형 제외 | |
| 회색 라벨 상자를 놓침 | 잉크 임계가 연함 | `채도>12 or 밝기합<735` | |
| 화살표 그라데이션 방향이 위→아래 | COM `msoGradientHorizontal`=위→아래 | XML `a:lin ang=0` + `a:alpha` 직접 | 렌더 |
| 둥근 윗모서리가 별 모양 | `AutoShapeType=148` 추측 | XML `prstGeom round2SameRect` | |
| '디자인' 말풍선을 지우다 조직도 상자까지 | 글자로만 찾음 | 이름 `말풍선` + 글자, 지우기 전 목록 | |
| 목차 한 항목만 색이 다름 | 그 런만 `schemeClr tx1` | 문단별 런 색 대조 → 다수 색으로 | 렌더 크롭 |
| 머리와 본체 사이 흰 쐐기 | 본체 roundRect | round2SameRect `rot=10800000` + `bodyPr rot=-10800000`, tIns/bIns 맞바꿈 | 렌더 |
| 인물이 바깥을 봄 | 자산 방향 | `flipH`(글자 든 그림은 교체) | 인물 시트 |
| 그림·지도가 너무 진함 | 불투명 | blip `alphaModFix amt` | 렌더 |
| 자동 번호 목록 1차 항목을 못 찾음 | 번호가 텍스트에 없음 | COM `IndentLevel==1` | |
| 조건에 0건(표·카드) | 대상이 그룹 안 | 최상위 목록부터 확인, 그룹째 조작 | |
