# 표준 9단계 — 단계별 상세

> 시작 전: `quality-bar.md` 와 기준 그림 `gold-sample/` 를 본다. 5단계에서 글 덩어리는 기준 부품(특징 카드·번호 목록·단계 칩·소카드·결론 띠)으로 다시 짤 대상에 넣는다. 9단계 눈검수는 기준 장과 나란히 놓고 한다.

모든 명령은 `D:\powerPlus\tools\ppt-pipeline` 에서 실행한다.

```bash
PY="C:/Users/<사용자>/AppData/Local/Python/pythoncore-3.14-64/python.exe"
cd D:/powerPlus/tools/ppt-pipeline
```

- COM 도구는 PowerPoint 가 설치돼 있어야 하고, 대상 파일이 PowerPoint 에서 열려 있으면 실패한다(사용자가 연 파일은 새 이름으로).
- 스크립트는 전부 파일로 실행한다. `python -` 인라인·heredoc 은 스토어 스텁·백슬래시 탈락으로 멈추거나 깨진다.
- 판 사이 중간 산출물은 `제안서/_work/step<N>.pptx` 처럼 두고, 판이 확정되면 `_vN.N_<한일>.pptx` 로 저장.

---

## 1 · 원본 동결

- 받은 파일을 `<이름>.원본백업.pptx` 로 복사하고 납품 때까지 지우지 않는다.
- 이유: 오교체는 "원본에 무엇이 있었나" 대조로만 잡힌다. 착수보고에서 원본 **아래화살표를 픽토그램으로 오인해 모니터 아이콘을 넣어 둔 것**을 백업 대조로 찾았다.
- 판 이름: `<이름>_v0.1_디자인요청` → `v0.2_톤정리` → `v0.3_최종` → `v0.4_가이드정렬` → `v0.5_세트아이콘` → `v0.6_톤통일` 처럼 **한 판 = 한 주제**.

## 2 · 실측 — 손대기 전에 숫자부터

```bash
"$PY" tone_audit.py <원본.pptx>                 # 서체 계열(글상자 기본값 포함)·7pt 미만·팔레트 밖 색·합성 굵게·형제 크기 차
"$PY" tone_overflow.py <원본.pptx> k_orig.json  # 넘침을 위치 키(슬라이드|이름|left|top)로 저장 — 4단계 대조 기준
"$PY" pic_survey.py <원본.pptx> survey 0.6      # 면적 0.6in² 이상 그림을 번호 시트로
"$PY" line_scan.py <원본.pptx>                  # 실제 렌더 줄로 어절 끊김·1~2글자 줄·넘침
"$PY" render.py <원본.pptx> thumbs               # 전 장 PNG
"$PY" sheet.py 1 20                              # 번호 컨택트시트(thumbs/ 기준)
```

동시에 **손대면 안 되는 것**을 가른다.

| 종류 | 예 | 왜 |
|---|---|---|
| 기획용 메모 | 노란 스마일 말풍선·'애매' | 장표를 구분하려고 넣은 표시 |
| 지시 마커 | 분홍 '디자인' 말풍선 | 9단계에서 제거(이름+글자로 식별) |
| 증빙 화면 캡처 | 실제 시스템 화면 | 교체하면 증빙이 아니다 |
| 인증서·로고·인물 사진·지도 | CMMI 인증서, 회사 로고 | |
| 문서 썸네일 | '보고서(예시)' 1~2pt 글자 그림 | 표로 다시 만들면 7pt 로 안 들어가고 역할도 '예시 그림' |

> 🔸 **컨폼 ①** 건드리면 안 되는 목록

## 3 · 기준 확정 — 디자인 가이드

`references/guide-template.md` 를 복사해 `제안서/<프로젝트>_디자인가이드.md` 로 만든다.

- 서체 3역할(제목/본문/강조) — **굵기가 아니라 역할**로.
- 팔레트: 그 장표에서 **많이 쓰인 색**을 대표로 20개 안팎. 내가 새 색을 고르지 않는다.
- 글자 크기: 정수 pt 목록, 최소 7pt.
- 선: 도식 선 규격(OO시 0.5pt·25% / 착수보고 0.75·1pt·30%).
- 여백·가이드: 실측 최빈값, 안내선 값.

> 🔸 **컨폼 ②** 서체와 팔레트 — **결과가 절반씩 갈리는 유일한 결정**이라 여기서만 묻는다(OO시: "본문 a시월구일2 / 강조 3 / 제목 G마켓 유지").

## 4 · 톤 일괄 — 순서가 중요하다

**서체 → 넘침 흡수 → 색 → 크기.** 이 순서라야 색·크기가 줄바꿈을 안 건드린다.

```bash
"$PY" tone_font.py     <src> s1.pptx            # 런 서체: 기본 본문, 흰 글자·12pt↑만 강조
"$PY" font_inherit.py  s1.pptx s1b.pptx         # lstStyle/테마 기본값을 물려받는 글자까지
"$PY" tone_overflow.py s1b.pptx k_new.json      # 원본과 위치 키로 비교 → 새로 넘친 것만 fixlist.json
"$PY" tone_fit.py      s1b.pptx s2.pptx fixlist.json   # 0.25pt 씩 최대 2pt
"$PY" tone_color.py    s2.pptx - 105            # '-' = 시뮬레이션, 임계 105
"$PY" tone_color.py    s2.pptx s3.pptx 105
"$PY" tone_size.py     s3.pptx s4.pptx          # 소수 pt 내림
"$PY" tone_audit.py    s4.pptx                  # 3계열 밖 0, 팔레트 밖 = 설명 가능한 잔여만
```

- 흰 글자 판정: `srgbClr FFFFFF` + **`schemeClr bg1`** + `prstClr white` + 도형 스타일 `fontRef lt1`.
- 서체를 바꾸면 **폭이 달라져 줄바꿈이 새로 생긴다** → 8-1 을 다시 돌린다.
- 원본에 이미 있던 넘침은 디자인 의도일 수 있어 두고, **새로 생긴 것만** 고친다(OO시 69→68, 새 27곳 흡수).

## 5 · 교체·재제작 대상 확정

```bash
"$PY" pic_survey.py <src> survey 0.6            # 그림 번호 시트
"$PY" extract.py <src> icons <시작슬라이드>     # 아이콘 후보 + 좌표로 가까운 글자 3개(거리 포함)
"$PY" iconsheet.py icons
"$PY" shape_scan_circle.py  <src> <시작> && "$PY" shape_scan_cluster.py <src> <시작>   # 도형 아이콘
"$PY" crop_groups.py ...                        # 자리 크롭 시트로 판정(마킹 위 판정 금지)
```

| | 대상 | 다음 |
|---|---|---|
| ⓐ | 아이콘·인물 일러스트 | 6단계 — powerPlus 세트로 |
| ⓑ | 이미지로 박힌 도식·표 | 7단계 — 도형+텍스트로 재제작 |
| ⓒ | 사진·증빙·로고·장식 | 그대로 |

- 판별 기준: 표시 0.9in 이하·종횡비 0.65~1.5 = 아이콘, 그 이상 = 일러스트.
- 도식은 면적 0.6in² 이상 그림을 시트로 판독(OO시 130개 중 15건).
- 결과를 가이드 문서 표(슬라이드·도식·크기·말풍선 유무)로 남긴다.

> 🔸 **컨폼 ③** 세 목록과 우선순위

## 6 · 그림 교체 (powerPlus) — 자세히는 `powerplus.md`

1. 세트 결정: 아이콘 3D 295종(`icon_1263` 세트) · 인물 3D 94종(`illust_187` 세트). 스크린샷 개수와 대조해 세트 확정(지문으로 갈린 47종 세트와 혼동 주의).
2. 자리마다 종류 판정 → 후보를 시트로 → 지정표 `set_swap.<프로젝트>.json` 작성: `[[슬라이드, "도형이름", "lib/icon_1397.png", 같은이름순번], ...]`
3. `"$PY" set_swap.py <src> <dst> set_swap.<프로젝트>.json`
4. 덩어리감: `"$PY" mass_even.py <dst> <dst2> targets.json` (targets = `[[슬라이드, "이름", 순번, "icon"|"illust"]]`)
5. 중복: `"$PY" icon_dedupe.py ...` — 같은 장 같은 아이콘 금지.
6. 렌더로 확인 — **렌더에 보이는 그림**을 기준으로(박스 뒤에 가려진 그림을 바꾸지 않게).

## 7 · 도식·표 재제작

- **유형끼리 묶어서** 한다(플로우차트끼리·표끼리·단계도끼리) — 건별로 하면 15건이 15가지 스타일.
- 각 건: 원본 확대 판독 → 구조 분해(노드·연결·라벨) → `diagram/d_sNN.py` 명세 작성(원본 px 좌표 그대로) → `run_diag.py` → **원본과 나란히 렌더 비교** → `finish()` 가 z-순서 자리에 넣고 원본 그림 삭제.
- 이미 손본 판 위에 다시 지을 땐 `diagram/rebuild_on.py`(옛 그룹을 찾아 교체).
- 규칙: 기본 7pt, 마름모·셰브런은 **위에 글상자를 따로 얹는다**, 표는 PowerPoint 표, 화살표 단계도는 `arrow_gradient.py` 규칙, 같은 장 아이콘 중복 금지(새 도식도 검사 대상).
- 이어서 전 장: `"$PY" diagram_lines.py <src> <dst>` (선 규격) · `"$PY" color_unify.py <src> <dst>` (회색→파랑 밝기표) · `"$PY" diagram_roles.py <src> <dst> "20:Group 14" ...` (도식 간 역할 색 한 벌 — 가이드 역할표 먼저).

> 🔸 **컨폼 ④** 재제작 첫 1건의 형식. 이후는 묶음 단위로 보고.

## 8 · 마감 — 글자·여백·자간·가이드

```bash
"$PY" text3d_off.py   <src> a.pptx     # 글상자 3D 제거(흰 얼룩)
"$PY" spc_relax.py    a.pptx b.pptx    # -10%보다 좁은 자간 → -5%
"$PY" fit_breaks.py   b.pptx c.pptx    # 어절 끊김: 0.25pt 축소 → 어절 앞 줄바꿈 → 목록 보고
"$PY" orphan_balance.py c.pptx d.pptx  # 고아 줄: 윗줄 마지막 어절 앞 줄바꿈(크기 불변)
"$PY" margin_even.py  d.pptx e.pptx    # 좌측 정렬 글 좌우 0.08in
"$PY" render.py e.pptx r_e && "$PY" guide_align.py e.pptx r_e f.pptx   # 가이드 맞춤(렌더 픽셀 기준)
"$PY" line_scan.py f.pptx              # 새 끊김 0 확인
```

8-1 줄바꿈 우선순위: ① 0.25pt 씩 최대 -2pt(7pt 하한) ② 어절 앞 `chr(11)` ③ 도형 넓히기·문구 줄이기 → **목록 보고**. 한 어절이 줄보다 긴 합성어(연계표준가이드라인)는 **띄어쓰기로 푸는 게 정답**(문구 변경이라 보고).

8-2 여백: 세로 중심은 박스가 아니라 `BoundTop/BoundHeight`. 이동량 상한 0.12~0.25in. 스택(아이콘 위·글자 아래) 구조는 제외.

8-3 색 2차: 튀는 색은 **사용 빈도 최다 색**으로. 그라데이션 스톱 제외, 임계 넘는 색은 남기고 보고.

## 9 · 전수 재검수 → 마커 제거 → 납품 — 자세히는 `review.md`

1. 전 장 렌더 컨택트시트 눈검수 + 자동 감사(`tone_audit` · `line_scan` · 필요시 `audit_checklist`) **3회 반복**.
2. 분홍 '디자인' 말풍선 제거 — 도형 이름 `말풍선` **+** 글자 둘 다 조건, 지우기 전 목록 출력(조직도 '디자인' 역할 상자 오삭제 방지).
3. 점수표(9×10) 작성, 남은 예외에 이유를 단다.
4. 최종 렌더 1회 → PowerPoint 로 열어서 전달.
