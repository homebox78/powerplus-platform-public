# 재검수 — 매 판 끝

## 절차 (3회 반복)

1. **렌더**: `render.py <판.pptx> r_vN` → `sheet.py` 로 4열 번호 컨택트시트.
2. **눈검수**: 시트를 한 장씩 Read — 회귀(겹침·잘림·빈 자리·색 튐·아이콘 사라짐)를 찾는다. 의심 지점은 원본과 **같은 좌표** 크롭으로.
3. **자동 감사**
   - `tone_audit.py` — 3계열 밖 서체 0 · 팔레트 밖 색(메모 제외) · 6.5pt 미만 · 합성 굵게 · 형제 크기 차
   - `line_scan.py` — 어절 끊김 · 1~2글자 줄 · 넘침(전 판과 diff)
   - `tone_overflow.py` — 원본 대비 새 넘침
   - 착수보고류는 `audit_checklist.py`(그 장표 지시 13항목을 코드화한 것 — 다른 장표엔 선 규격 등을 그 장표 가이드로 바꿔 쓴다)
4. **위반 목록 → 보정 후보** — 한 건씩 보정 → 렌더 확인 → 깨지면 원위치. 어떤 규칙에도 깨지는 장은 규칙에서 영구 제외(SKIP).
5. 2~4 반복. 1회차에 회귀가 나오는 게 정상(착수보고 1회차 회귀 8건 → 3회차 0).

목표 = "남은 건이 전부 설명 가능한 예외". 예외 목록에 장·이유를 적는다.

## 베테랑 디자이너 눈검수 체크 (사용자 지시 "30년차 관점으로 부족한 디자인을 찾아 보강")
자동 감사가 못 잡는 '보기 좋음'을 매 판 시트에서 본다. 찾으면 고치고 증적에 남긴다.
1. **허전한 자리** — 상자·패널 안에 글 없이 비어 있는 폭 1.5in·높이 0.8in 이상 영역(OO시 s26 gap 상자 좌우, s29 기술이전 상자 좌우, s39 화살 옆). 뜻 맞는 장면 일러스트나 아이콘으로 채운다(`fill_add.py`). 간지는 배경 모티프가 의도라 제외.
2. **스타일 섞임** — 한 장 안에 3D 인물과 평면 인물, 옛 평면 아이콘과 3D 아이콘이 같이 있는지.
3. **작아서 안 읽히는 그림** — 0.5in 아래 장면 일러스트는 형체만 남는다 → 아이콘으로 바꾸거나 키운다.
4. **덮음·잘림** — 새 그림이 머리 띠·화살 끝·슬라이드 밖·글자를 덮는지(렌더 좌표로).
5. **시선 흐름** — 좌→우·위→아래 읽는 순서대로 무게가 놓였는지, 한쪽만 무거운 장.
6. **정렬·간격** — 같은 줄 그림 발밑·윗선, 같은 역할 상자 간격 한 벌.
8. **글이 그림에 묻히지 않았나** — 카드마다 글이 먼저 읽히는지, 아이콘이 글보다 크지 않은지(OO시 회고).
9. **원본과 같은 말·같은 강조인가** — 원본 렌더를 옆에 놓고 문장·연결선·강조 칸을 대조(`text_diff.py`).
7. **서체 역할** — 키메시지만 G마켓, 나머지 굵은 제목 a시월구일4, 본문 a시월구일2/3 — 역할 밖 서체가 섞이지 않았는지.

## 기준 그림과 나란히 (quality-bar)
- 결과 장마다 `gold-sample/` 의 같은 성격 장(목록형·도식형·카드형)을 옆에 놓은 시트를 만든다.
- 기준보다 글이 크다 / 빈 곳이 크다 / 글 덩어리가 그대로다 → 다시 짠다.
- `text_stats.py <결과> 제안서/_gold/OO시_제안요약서_gold.pptx` 로 글자 크기 분포를 비교한다. 9.5pt 이상 본문이 기준(약 2%)보다 많으면 줄인다.

## 점수표 (9×10)

| 단계 | 기준 | 근거 |
|---|---|---|
| 1 | 원본·이전 판 보존, 새 판 저장 | 파일 목록 |
| 2 | 실측 결과가 문서에 | tone_audit·pic_survey 출력 |
| 3 | 가이드가 최신 규칙 반영 | 가이드 절 번호 |
| 4 | 3계열 밖 서체 0 · 팔레트 밖 색 0 | tone_audit |
| 5 | 교체/재제작/유지 목록 확정 | 지정표 json |
| 6 | 세트 통일 · 덩어리감 · 회귀 없음 | 렌더 크롭 |
| 7 | 선 규격 · **도식 간 색 역할 한 벌** · 겹침 없음 | diagram_lines·color_unify·diagram_roles 로그 + 도식 장 시트 |
| 8 | 새 끊김 0 · 고아 줄 · 여백 | line_scan diff |
| 9 | 눈검수 3회 + 감사, 남은 건 전부 예외 설명 | 시트·예외 목록 |

감점 기준: 눈검수 3회 미만 −2, 예외에 이유 없음 −1/건, 문구 변경 미보고 −2.

## 흔한 예외(설명 가능)
- 템플릿 두 줄 제목 자리(화면 정상) · 의도된 두 줄 라벨
- 노랑 기획 메모
- 원본부터 6pt 도해(7pt 로 올리면 넘침)
- 문서 썸네일 이미지(1~2pt 글자)
- 삽화 비율 때문에 가이드 세로 제외 · 장식이 밖으로 번지는 디자인

## 전달
- 파일을 `Start-Process` 로 PowerPoint 에서 연다.
- 채팅 보고: 판 파일명 / 한 일 수량 / 문구 바꾼 곳(확인 요청) / 남은 예외 / 점수.
- 가이드 md 에 판 절 추가, `evidence.md` 맨 위 항목 추가.

## 원본 대조 — 재제작·시안 반영 뒤 반드시 (OO시 v0.69, 사용자 지시 "원본과 비교해서 빠진 것·문구 잘못된 것 체크")
디자인을 다시 짜면 **글이 줄고 사실이 바뀐다**. 눈검수·자동 감사는 "보기"만 봐서 못 잡는다(이번 누락 중 눈검수로 잡힌 건 0건).
1. **글 대조**: `text_diff.py <원본백업> <최종> <폴더>` — 장별 원본/최종 글, '원본에만(빠짐 후보)', '최종에만'. 공백·기호 무시 비교. 후보는 단순 문자열이라 말 바꿈·합침·그림 속 글이 섞인다.
2. **원본 렌더**: 원본을 COM 으로 PNG(원본은 도식이 그림인 경우가 많아 글 추출에 안 잡힌다). PowerShell 에서 결과 폴더 변수를 `$S` 로 쓰고 `foreach($s in ...)` 를 돌리면 대소문자 구분이 없어 변수가 덮인다 → 다른 이름.
3. **판정은 에이전트 병렬**(장 5~7개씩): 원본·최종 렌더 둘 다 보고 **MISSING-IMPORTANT(수치·시스템명·단계·약속·목록 통째) / MISSING-MINOR / WORDING-ERROR(오타·수치·이름·뜻 변경·비문)** 로 가르고 `fix` 에 넣을 문구까지 JSON. 글 차이 없는 장은 오타 교정만. 도식이 그림이던 장은 "옮겨 적은 글이 원본 그림과 같은가"로 지시.
4. **바로 고치는 것**: 띄어쓰기·맞춤법·쪽 번호·비문·뜻이 뒤집힌 문장(예: 제안사가 '승인'), 사용자가 지목한 누락. `sample_fix69.py` 형식(장별 (옛, 새) 목록, 런 걸침 처리, 표는 행 라벨로 칸 찾기).
5. **묻는 것**: 시안 때문에 줄인 내용을 되살릴지(시안 우선 결정과 충돌), 원문과 어긋나는 사실(역할·거주지·등급 표기), 원본부터 근거가 불분명한 쪽 번호.
6. 고친 뒤 `line_scan` 으로 **새로 생긴 줄바꿈 끊김** 확인 — 띄어쓰기를 넣으면 줄 끝에서 단어가 잘린다(OO시 25·29쪽). 단어 앞 줄바꿈은 `linebreak_mark.py`. 문장을 바꾼 칸은 렌더 크롭으로 넘침 확인(OO시 12쪽).
- 결과 JSON 은 `제안서/원본대조_vX/` 에 남긴다(다음 판에서 남은 항목 확인).
